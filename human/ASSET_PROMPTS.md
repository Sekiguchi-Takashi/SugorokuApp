# すごろく人生ゲーム 立ち絵プロンプト仕様

12人（プレイヤー6＋恋人候補6）× ライフステージ × 向き の生成用。
**同一人物として認識されることが最優先**なので、共通指定＋人物固定要素は毎回そのままコピーし、
ステージ部分だけ差し替える。

## 共通指定（毎回コピー）

```
チビキャラ（2.5〜3頭身）、全身、正面、直立、両足が見える、
アニメ塗り、太めの黒い輪郭線、影は最小限、
背景は完全な単色マゼンタ #FF00FF（グラデーション・影・小物・文字・キラキラ一切なし）、
被写体は画像中央、上下に余白を均等に、切れないこと、
1024×1024、正方形
```

- **背景は必ず単色マゼンタ**。こちらで colorkey 抜きして透過PNGにする
- 影・地面・キラキラを入れないこと（抜きの邪魔になる）
- 立ち位置・カメラ距離を毎回揃える（頭の上と足元の余白を一定に）

## プロンプトの組み立て（例：はやと・高校生）

```
チビキャラ（2.5〜3頭身）、全身、正面、直立、両足が見える、アニメ塗り、太めの黒い輪郭線、影は最小限、
背景は完全な単色マゼンタ #FF00FF（グラデーション・影・小物・文字・キラキラ一切なし）、
被写体は画像中央、上下に余白を均等に、1024×1024、正方形。

16歳の男子高校生。明るい茶色のツンツン跳ねたショートヘア、茶色の目、白い歯を見せて元気に笑う。
濃紺のブレザー制服（白いパイピングと胸のエンブレム）、白シャツ、赤ストライプのネクタイ、
グレーのチェックのスラックス、通学カバンを肩から提げる、ローファー。
```

同じ人物の別ステージを作るときは、**2段落目の年齢と服装だけ**を上の表から差し替える。

## 向き違い（`_s` 側面 / `_b` 背面）

盤面の駒は側面 `_s` を優先して使う。正面と体格・服・髪色が揃っていることが条件。

- 側面（`_s`）：共通指定の「正面」を **「真横（右向き）、進行方向は画面右、顔は横顔」** に置き換える
- 背面（`_b`）：**「真後ろ、顔は見えない、後頭部と背中、カバンは背中側に見える」** に置き換える
- 側面・背面は**同じステージの正面画像を参照画像として渡す**と一致率が上がる

## ファイル名と組み込み

- `human/src/main/res/drawable/chara_<stageKey><NN>.png`（例 `chara_univ07.png`）
- 向き違いは `chara_univ07_s.png` / `chara_univ07_b.png`
- こちらでマゼンタ抜き → 余白トリム → 512px 正方形 RGBA に統一してから配置
- `charas_human.json` の各キャラ `images` に `"univ": "chara_univ07"` を追記。**未定義のステージは近いステージの絵で自動代用**されるので、揃った分から入れられる

## 紹介ムービー

- `human/src/main/res/raw/intro_<基準画像名>.mp4`（例 `intro_chara_kid12.mp4` ＝さくら）
- 5秒前後、H.264 baseline / yuv420p / AAC / 1280×720
- 背景はマゼンタのまま生成してよい。こちらで colorkey 抜き＋背景合成する
